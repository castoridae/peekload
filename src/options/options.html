Peekload

On selected sites, exports (JSON, CSV/TSV, XML, text) open in a preview instead of being saved to disk.

Sites

The easiest way to enable a site is the extension icon in the toolbar. If an export comes from another domain (e.g. api.example.com), add it here separately. An entry like *.example.com covers the domain and all its subdomains; an exact entry (e.g. app.example.com) takes precedence over it. Under each site, choose which formats to capture — new sites capture JSON only.

    Behavior

    Popup, settings and preview. The extension name and description on the extensions page follow the browser language.

    Right after the preview opens.

    When the server sends a file in one of the enabled formats as an attachment (Content-Disposition: attachment). The extension pauses the download and fetches the file again with your session. Doesn't work for exports that require a POST request.

    What the Copy button puts on the clipboard for each format.
